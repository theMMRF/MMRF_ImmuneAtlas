# MMRF_ImmuneAtlas
Repository for Immune Atlas Research Consortium at MMRF for storing research project code.

Code used to generate certain figures will be located in the "manuscript_figures" folder.

A copy of the Cell Annotation Dictionary, which contains descriptions of the 106 individual clusters annotated in the MMRF Immune Atlas, is located in the "cell_annotation_dictionary" folder.

A public version of the Seurat object used as part of this analysis is located on Zenodo: https://zenodo.org/records/14624955. This object contains cell annotation information, but does not contain any clinical metadata.

For access to the original Seurat object used in this analysis, along with the individual FastQ files for all aliquots used in the study, please submit a request form to access the MMRF VLAB: https://mmrfvirtuallab.org. Further information on requirements to access this data is listed in the published paper.
